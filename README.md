# Monopoly Dice Control

This project is a Roblox script for the Monopoly game that allows players to control the dice rolls and manage their money. The script includes functionalities for rolling dice, moving players, and adding or subtracting money from player accounts.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio project.
3. Place the `MonopolyGame.lua` script in the `ServerScriptService`.
4. Place the `MonopolyUI.lua` script in the `StarterPlayerScripts`.
5. Place the `MonopolyController.lua` script in the `StarterPlayerScripts`.

## Use

1. Run the Roblox game.
2. Use the "Roll Dice" button to roll the dice and move the player.
3. Use the "Add Money" button to add money to the player's account.
4. Use the "Subtract Money" button to subtract money from the player's account.
